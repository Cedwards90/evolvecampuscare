

## Plan: Full PWA with Offline Support

### Important Note
PWA features (offline caching, install prompts) will only work on the **published version** of your app (`evolvecampuscare.lovable.app`), not in the Lovable editor preview. The service worker is intentionally disabled in the editor to prevent stale content issues.

### Overview
Install `vite-plugin-pwa`, create a web app manifest, configure Workbox for offline caching, add an iframe/preview guard so the service worker never interferes with the Lovable editor, and create PWA icons. The existing `OfflineContext.tsx` and manual `sw.js` registration will be replaced by the plugin's auto-generated service worker.

### Changes

**1. Install dependency**
- `vite-plugin-pwa`

**2. `vite.config.ts`** — Add VitePWA plugin
- Configure with `registerType: "autoUpdate"`, `devOptions: { enabled: false }`
- Add `navigateFallbackDenylist: [/^\/~oauth/]` to protect auth redirects
- Define manifest: name "Evolve Foundation", theme color `#3B82F6`, icons (192px + 512px)
- Cache strategies: CacheFirst for images/fonts, NetworkFirst for API calls

**3. `public/` icons** — Create PWA icons
- `pwa-192x192.png` and `pwa-512x512.png` (generated from the Evolve logo)
- `apple-touch-icon.png` for iOS

**4. `index.html`** — Add PWA meta tags
- `<meta name="theme-color" content="#3B82F6">`
- `<link rel="apple-touch-icon" href="/apple-touch-icon.png">`
- `<link rel="manifest" href="/manifest.webmanifest">` (auto-generated by plugin)

**5. `src/main.tsx`** — Add iframe/preview guard
- Detect if running inside an iframe or on a Lovable preview domain
- If so, unregister any existing service workers to prevent stale cache
- Otherwise, let the VitePWA auto-registration handle it

**6. `src/contexts/OfflineContext.tsx`** — Remove manual SW registration
- Remove the `navigator.serviceWorker.register('/sw.js')` block (the plugin handles this)
- Keep the online/offline detection logic

**7. Remove `public/sw.js`** (if it exists — currently it does not, so the registration was already failing silently)
